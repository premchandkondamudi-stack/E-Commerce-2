SIMPLE E-COMMERCE WEB APPLICATION

Technologies:
- HTML
- CSS
- JavaScript

Features:
- Product listing
- Product search
- Add to cart
- Increase/decrease quantity
- Remove from cart
- Automatic total calculation
- Checkout message
- Responsive design

How to run:
1. Extract the ZIP file.
2. Open index.html in a web browser.
3. No server or installation is required.

Note:
This is a frontend demo. Checkout does not process real payments or save orders to a database.
